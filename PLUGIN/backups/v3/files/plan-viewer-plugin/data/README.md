# Runtime data

Desde la versión 0.2.0 esta carpeta **no contiene planes ni decisiones de usuarios**.

- Codex/local: `.local/plan-viewer.db` (ignorado por Git).
- ChatGPT/producción: PostgreSQL configurado mediante `DATABASE_URL`.
- `PLUGIN/plans/` es documentación de desarrollo del proyecto, no almacenamiento runtime.

No añadas aquí exports de usuarios, tokens ni credenciales.
