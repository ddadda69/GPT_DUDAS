# Backup v1 del Plan Viewer Plugin

Snapshot autocontenido de la versión fuente `0.1.0`.

`files/` reproduce la estructura del plugin en el momento de crear este backup, incluyendo:

- manifest y configuración MCP;
- contratos;
- servidor;
- UI;
- skill propia del plugin;
- tests;
- planes de diseño;
- datos operativos iniciales y decisiones aprobadas;
- documentación.

El directorio `backups/` no se incluye dentro de `files/` para evitar recursión infinita.

No contiene tokens, contraseñas ni credenciales.
